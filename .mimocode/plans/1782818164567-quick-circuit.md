# Fix Edit/Delete for Movies

## Problem
- Edit (PATCH) and Delete (DELETE) fail with "failed to fetch"
- Delete was fixed by switching to `dlRequest` (no Content-Type header)
- Edit still broken — likely due to stricter body schema validation on PATCH route

## Root Cause
The movies PATCH route has `minLength: 1` on the `name` property in its body schema. Fastify's AJV validation rejects requests before they reach the handler. The working users PATCH route does NOT have this constraint.

## Fix

### File: `backend/routes/movies.js` (MODIFY)
Simplify the PATCH route body schema to match the users PATCH pattern — remove `minLength` constraint, let the controller handle validation:

```js
body: {
  type: "object",
  properties: {
    name: { type: "string" },
    rating: { type: "integer", minimum: 1, maximum: 5 },
    description: { type: "string" },
    genre: { type: "string" },
    duration: { type: "string" },
    imageUrl: { type: "string" },
  },
},
```

No other files need changes. The controller already validates name is not empty.
