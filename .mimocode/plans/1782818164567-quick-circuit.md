# Movies Feature — Implementation Plan

## Overview
Add a Movies feature: database table, backend API, and redesigned frontend with card grid and "Add Movie" modal for admin/moderator roles.

**Constraint**: No new npm packages. No changes to package.json or lock files.

---

## Step 1: Create Movie Model

**File**: `backend/models/Movie.js` (CREATE)

```js
// Follows exact conventions from User.js
id          - UUID (PK, UUIDV4)
name        - STRING, not null
rating      - INTEGER, not null (1-5)
description - TEXT, nullable
genre       - STRING, nullable
duration    - STRING, nullable (e.g., "2h 15m")
imageUrl    - STRING, nullable (field: "image_url") — stores a URL string
createdAt   - DATE, field: "created_at"

Options: tableName: "movies", timestamps: false
```

---

## Step 2: Create Movie Controller

**File**: `backend/controllers/movies.js` (CREATE)

### `listMoviesHandler`
- `Movie.findAll({ order: [["created_at", "DESC"]] })`
- Returns `{ movies: [...] }`

### `createMovieHandler`
- Reads JSON body: `{ name, rating, description, genre, duration, imageUrl }`
- Validates: name required, rating must be 1-5
- Creates Movie record
- Returns 201 with the created movie object

## Step 3: Replace Movies Routes

**File**: `backend/routes/movies.js` (REPLACE)

| Method | Path | Auth | Roles | Body |
|--------|------|------|-------|------|
| `GET`  | `/movies` | JWT | admin, moderator, user | — |
| `POST` | `/movies` | JWT | admin, moderator | JSON |

POST body schema:
```
name: string (required)
rating: integer 1-5 (required)
description: string (optional)
genre: string (optional)
duration: string (optional)
imageUrl: string (optional)
```

## Step 5: Add createMovie to API Client

**File**: `client/src/api/client.js` (MODIFY)

Add method to the `api` object:
```js
createMovie: (data) =>
  apiRequest("/movies", {
    method: "POST",
    body: JSON.stringify(data),
  }),
```

Uses existing `apiRequest` — standard JSON POST, no special handling needed.

## Step 7: Rewrite Movies Page

**File**: `client/src/pages/Movies.jsx` (REPLACE)
**File**: `client/src/pages/Movies.module.css` (REPLACE)

### Page Structure
1. Header row: title + "Add Movie" button (visible only for admin/moderator via `useAuth()`)
2. Card grid: `display: grid; grid-template-columns: repeat(auto-fill, minmax(260px, 1fr)); gap: 1.5rem`
3. Empty state, loading, error states

### Card Design (per movie)
- Poster image (2:3 aspect ratio, `object-fit: cover`) — or gradient placeholder if no URL
- Movie name (bold)
- Star rating (read-only StarRating)
- Genre badge (pill with accent-tinted background)
- Duration (muted text)
- Description (2-line clamp with `-webkit-line-clamp`)

### Modal (Add Movie)
Follows exact UsersList.jsx modal pattern:
- Overlay: `position: fixed; inset: 0; background: rgba(0,0,0,0.6); z-index: 100`
- Modal: `var(--surface)` bg, `var(--border)` border, `var(--radius)` radius, `var(--shadow)` shadow, `max-width: 480px`
- Fields:
  - Name: text input (required)
  - Rating: interactive StarRating (required)
  - Genre: select dropdown (Action, Comedy, Drama, Horror, Sci-Fi, Thriller, Romance, Documentary, Other)
  - Duration: text input, placeholder "e.g. 2h 15m"
  - Description: textarea
  - Image URL: text input, placeholder "Paste image URL"
- Error display via `className="form-error"`
- Cancel + Submit buttons (same style as UsersList modal)
- On submit: call `api.createMovie({...})`, refresh list, close modal
